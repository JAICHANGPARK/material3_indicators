## 0.0.1

* Initial release of `material3_indicators`.
* Added `ExpressiveLoadingIndicator` implementing Material 3 shape-morphing loaders with support for both contained and uncontained modes.
* Added `WavyLinearProgressIndicator` providing a linear progress bar with custom sinusoidal wave active tracks (determinate & indeterminate).
* Added `WavyCircularProgressIndicator` providing a circular progress ring with a polar wavy track.
* Added `ExpressiveShapes` with preset M3 configurations utilizing `StarBorder`.
* Includes an interactive example application displaying all indicators with parameter sliders.
